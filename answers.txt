
Q1: Why might we consider using Git?

Answer: Git tracks changes, lets a user recover older versions, and allows users to collaborate with one another. 

Q2: What field could data science be applied to? Give an Example.

Answer: Data Science can be used in computer science. For example, analyzing how people use an app can help developers improve its features. 

Q3: What is the difference between Merging and Rebasing?

Answer: Merging combines branches while preserving their existing commit history. Rebasing moves a branch's commits onto a new starting point, rewriting those commits to create a linear history.
